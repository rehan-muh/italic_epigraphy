{%- comment -%} Thousands separator. Liquid has no number-formatting filter, so the value is split at the thousands boundary and the remainder is zero-padded by adding 1000 and dropping the leading digit. Correct for 0 to 999,999. {%- endcomment -%} {%- assign _n = include.value -%} {%- if _n >= 1000 -%}{{ _n | divided_by: 1000 }},{{ _n | modulo: 1000 | plus: 1000 | slice: 1, 3 }}{%- else -%}{{ _n }}{%- endif -%}
